## 👋 关于我

你好，我是 **Huidian-drumer**。

我在探索一件很具体的事：如何把大模型的生成能力，变成**可控制、可追溯、不会轻易破坏用户成果**的创作产品。相比一次漂亮的演示，我更关心真实工作流里的版本安全、范围控制、失败保护与语义一致性。

- 🔭 目前专注于 AI 创作工具与作者工作台
- 🧩 喜欢把模糊的产品想法拆成可靠、可验证的系统
- ✍️ 正在持续打磨短剧文字创作体验
- 🌱 一边构建，一边学习更好的产品设计与工程实践
